# 🌐 ルーティング可視化シミュレーター

**ネットワークルーティングを体験的に学ぶWebアプリケーション**

Created by Dit-Lab.(Daiki ITO)  
Supported by Tomoaki ATSUMI

## 📝 概要

このアプリケーションは、ネットワークの「地図」とも言えるルーティングテーブルが、どのように作られ、どのように使われるのかを視覚的に探検（Explore）するシミュレーターです。ユーザーはデータパケットの気持ちになってネットワークの旅を体験し、ルーターが最適な経路を選択する賢い仕組みを直感的に理解することができます。

## ✨ 主な機能

### 1. インタラクティブなネットワーク図
- Plotlyを使用したインタラクティブなネットワーク構成図
- ルーターとネットワークノードの視覚的表示
- 経路ハイライト表示機能

### 2. パケットの旅路シミュレーション
- 出発地と目的地を選択してパケット送信をシミュレート
- パケットが経由するルーターでの処理を段階的に表示
- ルーティングテーブルを参照した経路決定プロセスの可視化

### 3. ルーティングテーブルの動的表示
- 各ルーターのルーティングテーブルをリアルタイム表示
- 宛先、ゲートウェイ、インターフェース、メトリック、プロトコルの詳細表示
- 各項目の分かりやすい解説付き

### 4. RIPシミュレーション
- RIP（Routing Information Protocol）の動作原理を段階的に学習
- 初期状態から完全な経路学習までの過程を可視化
- 情報交換プロセスの理解

### 5. 穴埋め問題モード
- ルーティングテーブルの理解度をチェックする問題
- 選択式問題と詳細な解説
- 経路の可視化による理解支援

### 6. プロトコル学習
- スタティックルーティング、RIP、OSPFの基本概念
- 各プロトコルの特徴と動作原理の解説

## 🚀 使用方法

### 1. 環境セットアップ

```bash
# 依存パッケージのインストール
pip install -r requirements.txt
```

### 2. アプリケーション起動

```bash
# Streamlitアプリケーション起動
streamlit run streamlit_app.py
```

### 3. 基本操作

1. **パケット送信シミュレーション**
   - 出発地と目的地ネットワークを選択
   - 「パケット送信」ボタンをクリック
   - 「パケット移動」ボタンで段階的に経路を確認

2. **RIP学習シミュレーション**
   - 「RIP情報交換開始」ボタンをクリック
   - 「次の段階」ボタンで情報交換プロセスを進行
   - 各段階でのルーティングテーブル変化を確認

3. **穴埋め問題**
   - 「穴埋め問題」ボタンをクリック
   - 問題の選択肢から正答を選択
   - 解説と経路可視化で理解を深める

## 🎯 教育目的

このシミュレーターは以下の学習目標をサポートします：

- ルーティングテーブルの構造と役割の理解
- パケット転送プロセスの理解
- ダイナミックルーティングプロトコルの動作原理
- ネットワーク経路選択アルゴリズムの理解
- ネットワーク障害時の経路変更メカニズム
